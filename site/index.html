flightlog

Record a coding-agent session as a portable, redacted bundle. Hand it to a colleague or another agent, attach it to a ticket, and resume it later in Claude Code, Codex, opencode, Gemini CLI or Cursor.

curl -fsSL https://flightlog.sh/install.sh | sh

macOS, Linux and Windows, x86-64 and arm64. Or cargo install flightlog · GitHub · format spec

# the newest session in this directory → one file
flightlog export
# claude_code session df9d8089…: 2167 steps, 32 native files, 11.1 MB
# redaction (review before sharing):
#   [REDACTED:password:1]   ×534  trajectory.json, native/…

# what's inside
flightlog inspect df9d8089….flightlog.zip

# back on any machine with the same repo checked out
flightlog restore df9d8089….flightlog.zip
# now run: claude --resume df9d8089…

What you get

Open format

The conversation is ATIF v1.8, the Agent Trajectory Interchange Format, inside a small manifest with a summary and checksums.

Redacted first

Keys, tokens, private keys and passwords become stable placeholders. You see the report before anything is shared.

Resumable

The tool's own session files come along, so the same session continues where it stopped.

One binary

A single static executable. No Python, no Node, nothing to configure.

Works with

Claude Code, Codex, opencode, Gemini CLI and Cursor (CLI and editor), on macOS, Linux and Windows. Bundles upload to any presigned URL, or straight to a task in Inside.

Teach your agent

Two skills tell an agent how to save its session and how to pick one up again.

flightlog skills install     # Claude Code, Codex, opencode, Copilot, Cursor, Gemini CLI

# or as a plugin
claude plugin marketplace add skrcka/flightlog
codex plugin marketplace add skrcka/flightlog
gemini extensions install https://github.com/skrcka/flightlog

The bundle format is open: SPEC.md, with the conversation in ATIF v1.8.
